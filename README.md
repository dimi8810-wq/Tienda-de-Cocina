# Cocina Profesional Site

Este es un proyecto de un sitio web de cocina profesional. A continuación se detallan los archivos y cómo configurar el entorno para ejecutarlo localmente.

## Estructura del Proyecto

```
cocina-profesional-site
├── public
│   ├── index.html        # Documento HTML principal del sitio web
│   ├── css
│   │   └── styles.css    # Estilos CSS para el sitio web
│   └── js
│       └── main.js       # Código JavaScript para funcionalidades interactivas
├── server.js             # Configuración del servidor Node.js
├── package.json          # Archivo de configuración de npm
└── README.md             # Documentación del proyecto
```

## Requisitos

- Node.js
- npm (Node Package Manager)

## Instalación

1. Clona este repositorio en tu máquina local:
   ```
   git clone <URL_DEL_REPOSITORIO>
   ```

2. Navega al directorio del proyecto:
   ```
   cd cocina-profesional-site
   ```

3. Instala las dependencias necesarias:
   ```
   npm install
   ```

## Ejecución

Para iniciar el servidor y acceder al sitio web en tu navegador, ejecuta el siguiente comando:
```
node server.js
```

Luego, abre tu navegador y visita `http://localhost:3000` para ver el sitio web en acción.
